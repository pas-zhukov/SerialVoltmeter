### 🐛 Исправленные проблемы

1. **Критические:**
   - Зависание при ошибке инициализации АЦП
   - Переполнение millis() через 49 дней работы
   - Блокировка UI при большом потоке данных
   - Потеря 86% данных из-за несинхронизированных частот

2. **Средней важности:**
   - Неэффективная отрисовка графика (полная перерисовка)
   - Отсутствие ограничения данных в памяти
   - Жестко закодированные параметры в Arduino
   - Неиспользуемые файлы Parser.h и AsyncStream.h

3. **Мелкие:**
   - Отсутствие логирования
   - Некорректная логика пропуска измерений
   - Отсутствие обработки специфичных исключений

### API изменения

#### Arduino
Новые команды через Serial:
- `SET_RANGE,<value>` - установить диапазон напряжения
- `SET_RATE,<value>` - установить частоту дискретизации
- `SET_INTERVAL,<ms>` - установить интервал отправки
- `GET_CONFIG` - получить текущую конфигурацию
- `RESET_COUNTER` - сбросить счетчик измерений

#### Python
Новые модули и классы:
- `SerialReaderThread` - поток для чтения данных
- `DataBuffer` - буфер с ограничением размера
- `DataFileWriter/Reader` - работа с файлами
- `PlotManager` - управление графиками
- `ArduinoConfig` - настройка Arduino
- `Statistics` - расчет статистики
- `PeakDetector` - детекция пиков
- `TriggerDetector` - детекция триггеров
