# Руководство по миграции на Serial Voltmeter v2.0

## 🎯 Краткая инструкция

### Шаг 1: Сохраните ваши данные
```bash
# Сделайте резервную копию всех файлов измерений
mkdir backup
copy measurements*.csv backup\
```

### Шаг 2: Обновите Arduino

1. Откройте Arduino IDE
2. Загрузите файл `arduino/main/main.ino`
3. Убедитесь, что файлы `Parser.h` и `AsyncStream.h` находятся в той же папке
4. Прошейте Arduino

**Важно:** После прошивки Arduino будет использовать новый протокол. Старое приложение v1.x не будет работать с новой прошивкой!

### Шаг 3: Установите зависимости Python

Если вы еще не установили зависимости или обновили Python:

```bash
# Используя pip
pip install -r requirements.txt

# Или используя Poetry
poetry install
```

### Шаг 4: Запустите приложение

```bash
python app.py
```

или

```bash
poetry run python app.py
```

## 🐛 Решение проблем

### Arduino не подключается
1. Проверьте правильность порта в диспетчере устройств
2. Убедитесь, что драйверы установлены
3. Попробуйте режим "Авто" при подключении
4. Проверьте, что другие программы не используют порт

### Ошибка инициализации АЦП
1. Проверьте подключение SDA и SCL (пины A4 и A5)
2. Проверьте питание ADS1115
3. Проверьте адрес I2C (по умолчанию 0x48)
4. Arduino будет автоматически переподключаться каждые 5 секунд

### Низкая производительность графика
1. Убедитесь, что используется pyqtgraph (по умолчанию)
2. Уменьшите размер окна графика
3. Увеличьте интервал отправки данных
4. Проверьте загрузку CPU

### Потеря данных
1. Убедитесь, что интервал отправки синхронизирован с частотой АЦП
2. Проверьте качество USB-соединения
3. Проверьте загрузку системы
4. Увеличьте размер буфера (в constants.py)
