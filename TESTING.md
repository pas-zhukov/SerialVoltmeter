# Руководство по тестированию Serial Voltmeter

## 🧪 Тестирование без реального Arduino

Для тестирования Python приложения без реального устройства используйте симулятор Arduino.

## 📦 Установка виртуальных Serial портов

### Windows

#### Вариант 1: com0com (Рекомендуется)

1. Скачайте com0com: https://sourceforge.net/projects/com0com/
2. Установите драйвер (может потребоваться отключение проверки подписи драйверов)
3. Запустите Setup Command Prompt
4. Создайте пару портов:
   ```
   install PortName=COM3 PortName=COM4
   ```
5. Теперь COM3 и COM4 связаны: данные из COM3 идут в COM4 и наоборот

#### Вариант 2: Virtual Serial Port Driver

- HHD Software Virtual Serial Port: https://www.hhdsoftware.com/
- Eltima Virtual Serial Port Driver: https://www.virtual-serial-port.org/

### Linux

Используйте `socat` для создания виртуальных портов:

```bash
# Установка socat
sudo apt-get install socat  # Ubuntu/Debian
sudo yum install socat      # CentOS/RHEL

# Создание пары виртуальных портов
socat -d -d pty,raw,echo=0 pty,raw,echo=0
```

Команда выведет что-то вроде:
```
2024/02/08 10:00:00 socat[12345] N PTY is /dev/pts/2
2024/02/08 10:00:00 socat[12345] N PTY is /dev/pts/3
```

Используйте `/dev/pts/2` и `/dev/pts/3` как виртуальные порты.

### macOS

macOS имеет встроенную поддержку виртуальных портов:

```bash
# Создайте пару портов с помощью socat
brew install socat
socat -d -d pty,raw,echo=0 pty,raw,echo=0
```

## 🚀 Запуск симулятора

### Базовое использование

1. **Создайте виртуальные порты** (см. выше)

2. **Запустите симулятор** на одном порту:
   ```bash
   python arduino_simulator.py --port COM3
   ```
   
   Для Linux/macOS:
   ```bash
   python arduino_simulator.py --port /dev/pts/2
   ```

3. **Запустите приложение** и подключитесь к парному порту (COM4 или /dev/pts/3)

### Просмотр доступных портов

```bash
python arduino_simulator.py --list
```

### Запуск с подробным логированием

```bash
python arduino_simulator.py --port COM3 --verbose
```

### Настройка скорости передачи

```bash
python arduino_simulator.py --port COM3 --baud 9600
```

## 🧪 Сценарии тестирования

### Тест 1: Базовое подключение

1. Запустите симулятор:
   ```bash
   python arduino_simulator.py --port COM3
   ```

2. Запустите Serial Voltmeter:
   ```bash
   python app.py
   ```

3. Подключитесь к COM4 (парный порт)
4. Проверьте:
   - ✅ Сообщения инициализации в консоли
   - ✅ График отображает синусоиду
   - ✅ Данные обновляются в реальном времени

### Тест 2: Запись данных

1. Подключитесь к симулятору
2. Нажмите "Начать запись"
3. Подождите 10-30 секунд
4. Остановите запись
5. Проверьте:
   - ✅ CSV файл создан
   - ✅ Данные корректно записаны
   - ✅ Файл можно открыть для просмотра
   - ✅ График отображает данные из файла

### Тест 3: Настройка Arduino

1. Подключитесь к симулятору
2. Откройте меню "Настройки → Настройка Arduino и АЦП"
3. Измените параметры:
   - Диапазон напряжения: 2048 мВ
   - Частота дискретизации: 250 SPS
   - Интервал: 4 мс
4. Нажмите "Применить"
5. Проверьте:
   - ✅ В консоли появляются сообщения об изменении настроек
   - ✅ Данные продолжают поступать

### Тест 4: Получение конфигурации

1. Откройте диалог настройки Arduino
2. Нажмите "Получить конфигурацию"
3. Проверьте консоль - должна появиться строка:
   ```
   CONFIG: range=6144,rate=860,interval=1
   ```

### Тест 5: Сброс счетчика

1. Подключитесь и начните запись
2. Подождите несколько секунд
3. Откройте диалог настройки
4. Нажмите "Сбросить счетчик"
5. Проверьте:
   - ✅ Сообщение в консоли
   - ✅ Время на графике сбросилось

### Тест 6: Статистика

1. Подключитесь к симулятору
2. Начните запись
3. Следите за консолью - каждую секунду должна выводиться статистика:
   ```
   📊 получено: 860 | сохранено: 860 | время: 1.0 с | буфер: 860 точек
   ```
4. Проверьте корректность счетчиков

### Тест 7: Производительность

1. Подключитесь к симулятору
2. Начните запись на 60 секунд
3. Следите за:
   - ✅ Плавность отрисовки графика
   - ✅ Отсутствие пропусков данных
   - ✅ Загрузка CPU (должна быть <10%)
   - ✅ Использование памяти (стабильное)

### Тест 8: Потеря соединения

1. Подключитесь и начните запись
2. Остановите симулятор (Ctrl+C)
3. Проверьте:
   - ✅ Приложение определяет потерю соединения
   - ✅ Запись автоматически останавливается
   - ✅ Данные сохранены корректно

### Тест 9: Длительная работа

1. Запустите симулятор и приложение
2. Начните запись на 5-10 минут
3. Проверьте:
   - ✅ Стабильность работы
   - ✅ Отсутствие утечек памяти
   - ✅ Корректность данных
   - ✅ Размер буфера не растет бесконечно

### Тест 10: Открытие старых файлов

1. Откройте любой файл из записей v1.x
2. Проверьте:
   - ✅ Файл открывается без ошибок
   - ✅ График отображается корректно
   - ✅ Статистика рассчитывается

## 🎯 Что симулирует simulator

### Генерируемый сигнал

Симулятор генерирует составной сигнал:
- **Основная частота:** Синусоида 1 Гц, амплитуда 1000 мВ
- **Шум:** Гауссовский шум, σ = 5 мВ
- **Дрейф:** Медленная синусоида 0.1 Гц, амплитуда 100 мВ

Формула:
```
V(t) = 1000·sin(2πt) + N(0, 5) + 100·sin(0.2πt)
```

### Поддерживаемые команды

Симулятор полностью поддерживает протокол Arduino:
- `SET_RANGE,<value>` - изменение диапазона
- `SET_RATE,<value>` - изменение частоты
- `SET_INTERVAL,<ms>` - изменение интервала
- `GET_CONFIG` - получение конфигурации
- `RESET_COUNTER` - сброс счетчика

### Сообщения инициализации

При запуске симулятор отправляет:
```
INFO: Initializing ADC, attempt 1/10
INFO: Initializing ADC, attempt 2/10
INFO: Initializing ADC, attempt 3/10
INFO: ADC configuration completed
READY: ADC initialized successfully
```

## 🔧 Отладка

### Проблемы с виртуальными портами

**Windows:**
```powershell
# Проверить установленные порты com0com
list

# Удалить пару портов
remove 0

# Переустановить
install PortName=COM3 PortName=COM4
```

**Linux:**
```bash
# Проверить доступные порты
ls -l /dev/tty*

# Проверить права доступа
sudo chmod 666 /dev/pts/2
sudo chmod 666 /dev/pts/3
```

### Логирование симулятора

Для подробной отладки:
```bash
python arduino_simulator.py --port COM3 --verbose 2> simulator.log
```

### Проверка связи портов

**Windows:**
```powershell
# Отправить данные в один порт
echo "test" > COM3

# Читать из парного порта
mode COM4: BAUD=115200 PARITY=n DATA=8
copy COM4 CON
```

**Linux:**
```bash
# Отправить данные
echo "test" > /dev/pts/2

# Читать данные
cat /dev/pts/3
```

## 📊 Ожидаемые результаты

### График
- Плавная синусоида с небольшим шумом
- Медленный дрейф вверх-вниз
- Частота обновления: ~60 FPS

### Статистика
- Min: около -1100 мВ
- Max: около +1100 мВ
- Mean: около 0 мВ (может дрейфовать ±100 мВ)
- Std: около 5-10 мВ
- RMS: около 700-800 мВ

### Производительность
- CPU: 5-10%
- Память: стабильная (~100-200 MB)
- Скорость записи: ~860 измерений/сек

## 🎓 Дополнительные тесты

### Автоматическое тестирование

Для CI/CD можно создать автоматические тесты:

```python
# test_voltmeter.py
import unittest
from arduino_simulator import ArduinoSimulator, ADS1115Simulator

class TestSimulator(unittest.TestCase):
    def test_adc_range(self):
        adc = ADS1115Simulator()
        self.assertTrue(adc.set_range(2048))
        self.assertFalse(adc.set_range(9999))
    
    def test_sample_rate(self):
        adc = ADS1115Simulator()
        self.assertTrue(adc.set_sample_rate(250))
        self.assertFalse(adc.set_sample_rate(1000))
```

### Нагрузочное тестирование

Запустите несколько симуляторов одновременно для тестирования многоканального режима (будущая функция).

## 🐛 Известные ограничения симулятора

1. **Точность времени:** Может быть небольшая погрешность в интервалах
2. **Реалистичность сигнала:** Упрощенная модель реального АЦП
3. **Буферизация:** Симулятор работает быстрее реального Arduino
4. **Шум:** Генерируется псевдослучайно, не идентично реальному шуму
