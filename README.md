# Serial Voltmeter v2.0

Профессиональное приложение для записи и визуализации данных с Arduino-вольтметра на базе АЦП ADS1115.

## ✨ Основные возможности

### 📊 Измерение и запись
- Высокоскоростное измерение напряжения (до 860 SPS)
- Запись данных в CSV-файл в реальном времени
- Автоматическая остановка записи по таймеру
- Просмотр сохраненных данных с полным графиком
- Буферизованная запись для надежности

### 📈 Визуализация
- Быстрая отрисовка графиков в реальном времени (pyqtgraph)
- Настраиваемое скользящее окно
- Динамическое и фиксированное масштабирование оси Y
- Отображение количества точек и времени записи

### ⚙ Настройка Arduino и АЦП
- **Новое!** Настройка параметров АЦП без перепрошивки
- Выбор диапазона напряжения (256-6144 мВ)
- Выбор частоты дискретизации (8-860 SPS)
- Настройка интервала отправки данных
- Получение текущей конфигурации

### 📊 Статистика и анализ
- **Новое!** Статистика в реальном времени
  - Минимум, максимум, среднее значение
  - RMS (среднеквадратичное значение)
  - Стандартное отклонение
- **Новое!** Детектор пиков напряжения
- **Новое!** Детектор триггеров по пороговым значениям

### 🔧 Надежность
- Автоматическое переподключение при потере связи
- Многопоточная обработка данных (без блокировки UI)
- Обработка ошибок с повторными попытками
- Логирование всех операций

## Требования

- Python 3.8+
- PyQt5
- Matplotlib
- NumPy
- Pandas
- pyserial

## Установка

### Установка с помощью pip

```bash
pip install -r requirements.txt
```

### Установка с помощью Poetry

```bash
poetry install
```

## Запуск

```bash
python app.py
```

или с использованием Poetry:

```bash
poetry run python ./app.py
```

## Сборка исполняемого файла

Для сборки исполняемого файла (.exe) используйте Poetry:

```bash
poetry run python ./build.py
```

## 📁 Структура проекта

### Python приложение
- `app.py` - главный файл приложения
- `serial_handler.py` - многопоточная обработка Serial порта
- `file_handler.py` - работа с файлами данных
- `plot_widget.py` - виджеты графиков (matplotlib + pyqtgraph)
- `arduino_config.py` - настройка Arduino через Serial
- `statistics.py` - статистика и анализ данных
- `statistics_widget.py` - виджет отображения статистики
- `constants.py` - константы приложения
- `models.py` - модели данных
- `mainForm.ui` - интерфейс главного окна
- `comSelector.ui` - диалог выбора COM-порта

### Arduino
- `arduino/main/main.ino` - основной код для Arduino
- `arduino/main/Parser.h` - парсер команд
- `arduino/main/AsyncStream.h` - асинхронная обработка Serial
